# Свайп-клавиатура

Большая экранная клавиатура для Windows 10/11: слова набираются **свайпом**, как на смартфоне —
мышью, тачпадом или пальцем на сенсорном экране. Текст уходит в то окно, где мигает курсор
(браузер, мессенджер, Word, Блокнот…): клавиатура никогда не забирает фокус.

Один файл `SvajpKlaviatura.exe` (~2 МБ), без установки и без прав администратора.

## Как пользоваться

1. Запустите `SvajpKlaviatura.exe`. Внизу экрана появится клавиатура, в трее — значок.
2. Щёлкните в поле, куда нужно писать.
3. **Свайп:** зажмите кнопку мыши на первой букве слова, проведите через все буквы и отпустите
   на последней. Слово и пробел после него появятся сами.
4. Не то слово? Вверху клавиатуры — три других варианта: щелчок заменяет последнее слово.
   **⌫** сразу после свайпа стирает слово целиком.
5. Короткие слова и имена можно набирать по буквам щелчками; подсказки дополняют слово.
   Если слова нет в словаре, первая подсказка ««слово» +» добавит его.

**Тачпад:** кнопка «с зажатием / без зажатия» вверху (или пункт в меню значка) включает режим
«щелчок на первой букве → ведите пальцем → щелчок в конце». Правая кнопка отменяет жест.

| Действие | Как |
|---|---|
| Показать / скрыть | **Ctrl+Alt+K** (можно сменить в настройках), щелчок по значку, ✕ |
| Передвинуть | потянуть за верхнюю полосу |
| Размер | потянуть за правый нижний угол или меню значка → «Размер» |
| Русский / English | клавиша 🌐 |
| Цифры и знаки | ?123, затем =\< — ещё знаки, стрелки и Tab |
| Заглавные | ⇧ — одна буква/слово, двойное нажатие — Caps Lock; после «. ! ?» — сама |
| Прозрачность, тема | ⚙ → настройки |
| Мои слова | меню значка → «Мой словарь…» |
| Автозапуск | меню значка → «Запускать вместе с Windows» (HKCU\…\Run, без Планировщика) |

Настройки, выученные слова и журнал — в `%APPDATA%\SvajpKlaviatura`.

## Как распознаётся слово

Алгоритм основан на SHARK2 (Kristensson & Zhai, UIST 2004) и эластичном сопоставлении
жеста со словом, как в мобильных клавиатурах:

1. Траектория переводится в «клавишные» единицы (не зависит от размера окна) и ресэмплируется
   до 64 точек на равных расстояниях.
2. Отсев: первая буква — рядом с началом жеста, последняя — рядом с концом, длина
   идеальной ломаной слова сопоставима с длиной жеста (из 50 000 слов остаётся 1–5 тысяч).
3. Для каждого слова считаются каналы:
   * **проход по буквам** — каждая буква по порядку должна быть рядом с траекторией
     (динамическое программирование);
   * **упорядоченное покрытие (DTW)** — точки жеста по порядку ложатся на отрезки слова,
     лишние повороты штрафуются;
   * **местоположение и форма SHARK2** — попарное сравнение ресэмплированных точек до и после нормализации;
   * **длина** — разница длины жеста и ломаной слова.
4. Геометрия объединяется с частотой слова (словари OpenSubtitles) и с тем, что вы набираете
   сами: выбранные слова поднимаются, стёртые сразу после свайпа — опускаются.

Подробности и лицензии словарей — [docs/LICENSES.md](docs/LICENSES.md).

## Ограничения

* Окна, запущенные **от имени администратора**, не принимают ввод от обычных программ
  (защита Windows UIPI). Клавиатура предупредит; чтобы писать в такие окна, запустите и её
  от имени администратора.
* «⌫ стирает слово целиком» работает, пока вы не щёлкали в тексте и не печатали на обычной
  клавиатуре; после этого ⌫ стирает по одной букве.
* Без контекста предложения похожие слова («по»/«про», «of»/«off») различаются только частотой —
  второе слово всегда есть в подсказках.
* Файл не подписан: при первом запуске SmartScreen покажет «Система Windows защитила ваш компьютер» →
  «Подробнее» → «Выполнить в любом случае».

## Сборка

```
dotnet build SvajpKlaviatura.slnx -c Release
dotnet test tests/SvajpKlaviatura.EngineTests -c Release      # распознавание и логика набора (любая ОС)
dotnet run --project tools/Bench -c Release                    # отчёт о точности
```
CI (GitHub Actions, windows-latest): сборка, тесты, отчёт о точности, дымовой тест с настоящими
свайпами мышью в поле ввода и Блокнот (`ci/smoke.ps1`), снимки экрана, релиз по тегу `v*`.
