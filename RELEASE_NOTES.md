**Свайп-клавиатура 1.0.0** — экранная клавиатура для Windows 10/11: слова набираются свайпом мышью, тачпадом или пальцем, текст уходит в активное окно.

Скачайте `SvajpKlaviatura.exe` и запустите (установка и права администратора не нужны). При первом запуске Windows может показать «Система Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».

* Свайп по буквам с распознаванием слова (SHARK2 + DTW + частотные словари по 50 000 слов, русский и английский)
* 3 подсказки для замены слова, ⌫ стирает слово целиком, набор по буквам с дополнением
* ЙЦУКЕН и QWERTY, цифры, знаки, стрелки, Tab, ⇧ и Caps Lock, умная пунктуация
* Режим «без зажатия» для тачпада, сенсорный экран
* Обучение на ваших словах, «Мой словарь»
* Размер, прозрачность, тема, запоминание положения, значок в трее, Ctrl+Alt+K
* Окно никогда не забирает фокус (WS_EX_NOACTIVATE)

Ограничение: в окна, запущенные от имени администратора, Windows не пропускает ввод от обычных программ.
